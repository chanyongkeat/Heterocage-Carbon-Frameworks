# Heterocage Carbon Frameworks

Generation, relaxation and validation of heterocage carbon frameworks (C<sub>24</sub>/C<sub>20</sub>,
C<sub>36</sub>/C<sub>24</sub>, C<sub>60</sub>/C<sub>36</sub>) with intercage bonding.

| path | content |
|---|---|
| `GECOS.zip` ([Release](https://github.com/chanyongkeat/Heterocage-Carbon-Frameworks/releases/latest)) | AISP executable with GECOS, cage files, example inputs, `manual.pdf` |
| `MTP/` | trained machine-learning potentials (`pot.mtp`) and training sets |
| `GraphTheory/` | structure validation and classification code ([README](GraphTheory/README.md)) |
| `structures/` | all GECOS-generated structures reported in the manuscript |

## Workflow

### 1. Download

```bash
git clone https://github.com/chanyongkeat/Heterocage-Carbon-Frameworks.git
cd Heterocage-Carbon-Frameworks
wget https://github.com/chanyongkeat/Heterocage-Carbon-Frameworks/releases/latest/download/GECOS.zip
unzip GECOS.zip
cd GECOS
```

`GECOS.zip` is attached to the [latest Release](https://github.com/chanyongkeat/Heterocage-Carbon-Frameworks/releases/latest) (too large for the repository).
`GECOS/` contains the `AISP` executable, cage geometries (`C20.xyz`, `C24.xyz`, `C36.xyz`, `C60.xyz`),
example inputs (`aispC24C20.in`, `aispC36C24.in`, `aispC60C36.in`) and `manual.pdf`.

### 2. Generate structures with GECOS

GECOS (**G**raph theory **E**nhanced **C**omplex unit **O**rganizer) is a newly developed function of
[AISP](https://aisp.tech/). It generates heterocage structures with intercage bonding using
symmetry-guided assembly and graph-theory validation.

```bash
chmod +x AISP
./AISP -gen {input_file}     # e.g. ./AISP -gen aispC24C20.in
```

See `manual.pdf` for the input-file parameters.

### 3. Relax the structures

1. Coarse optimization with the trained MTP potential, `MTP/<system>/pot.mtp`
   (`C24C20`, `C36C24`, `C60C36`).
2. DFT relaxation to the local minimum.

### 4. Validate and classify

Use the code in `GraphTheory/` to check structure validity and classify the relaxed structures:

```bash
cd GraphTheory
pip install -r requirements.txt
python -m heterocage_graph CONTCAR --ref POSCAR
```

## Structures

`structures/C24C20`, `structures/C36C24` and `structures/C60C36` contain all structures generated by
GECOS reported in the manuscript (POSCAR format).
